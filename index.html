EDFA — เงื่อนไขการระบุ (Detection Logic)

อุปกรณ์ที่จัดว่าเป็น EDFA (Erbium-Doped Fiber Amplifier) คืออุปกรณ์ขยายสัญญาณแสงในระบบ PON ไม่ใช่ OLT ต้องเข้าเงื่อนไขครบทั้ง 3 ข้อ:

  • Vendor = ZTE
  • Model = C320
  • Device Name ลงท้ายด้วย E00 หรือ E01
# Python filter (used in all processing scripts)
is_edfa = (
  Vendor.str.upper().contains('ZTE') &
  Model.str.upper().contains('C320') &
  Name.str.upper().endswith(('E00','E01'))
)
df = df[~is_edfa]
